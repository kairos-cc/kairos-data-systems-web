# kairoscc.io website

Company site for **Kairos Consulting Collective, LLC**, served by GitHub Pages. No Paddle checkout runs here.

## Page hierarchy
| Path | Page |
|---|---|
| `/` | Company: who we are, what we do, products, contact |
| `/rackside/` | Rackside app: features, free and Pro, support |
| `/data-systems/…`, `/small-team/`, `/developer/`, `/legal/*` | Redirects to the Kairos Data Systems store |

## Kairos Data Systems store
The Lakehouse Factory, its Paddle checkout and its legal pages live at **datasystems.kairoscc.io** (repo `kairos-cc/datasystems-web`).
Paddle rejected kairoscc.io on Nov 23, 2026 because this site advertises IT, consulting and software development services, which Paddle doesn't support. Keep Paddle checkouts off this domain.
